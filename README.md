Deep Learning–Based Traffic Flow Prediction for Multi-Intersection Networks

TEKNOFEST 2025 – Intelligent Transportation Systems
Team: GCN Masters | Application ID: 3371467

🚦 Project Summary

  This project proposes a GCN (Graph Convolutional Network)–based traffic flow prediction and dynamic traffic light optimization system designed to manage urban traffic more efficiently across multiple interconnected intersections.
  
  The model leverages Chebyshev, Monomial, and Jacobi polynomial-based spectral filtering to learn spatial–temporal relationships and provide real-time traffic signal timing recommendations.

🎯 Objectives

  Reduce traffic congestion
  
  Improve travel times
  
  Minimize fuel consumption and environmental impact
  
  Enable dynamic, real-time traffic signal control

🧠 Methodology

  The traffic network is modeled as a graph structure.
  
  Spatial and temporal dependencies are learned using Graph Convolutional Networks.
  
  Chebyshev / Monomial / Jacobi polynomial filters capture multi-hop road interactions.
  
  Predictions are integrated into real-time signal optimization.
  
  A testing interface was developed using Gradio.

💾 Technologies

  Python
  
  PyTorch, NumPy, Pandas
  
  Gradio (UI)
  
  Datasets: PEMS04, local datasets from Konya and Kayseri intersections
  
  Evaluation metric: MAE

📊 Key Features
  
  Multi-intersection traffic flow forecasting
  
  Lower computational cost compared to deep RL models
  
  Scalable and adaptive smart transportation infrastructure
  
  Easy integration with municipal traffic systems
  
  No need for cameras or expensive hardware
  
🧪 Prototype Outputs

  Gradio-based demo interface
  
  Visualized traffic flow predictions
  
  Traffic light timing optimization suggestions

🌍 Target Audience

  Municipalities and Transportation Authorities
  
  Smart city R&D teams
  
  Logistics companies
  
  Academic researchers

🚦 Proje Özeti

  Bu proje, şehir içi trafik yönetimini daha verimli hale getirmek için çoklu kavşaklarda çalışan, GCN (Graph Convolutional Network) tabanlı bir trafik akış tahmin ve sinyal optimizasyon sistemi geliştirmeyi amaçlar.
  
  Geliştirilen model; Chebyshev, Monomial ve Jacobi tabanlı spektral filtreleme yöntemleri ile kavşaklar arası ilişkileri öğrenir ve gerçek zamanlı trafik ışığı sürelerini optimize edebilecek öneriler üretir.

🎯 Amaç

  Trafik sıkışıklığını azaltmak
  
  Seyahat sürelerini iyileştirmek
  
  Yakıt tüketimi ve çevresel etkiyi minimize etmek
  
  Gerçek zamanlı, dinamik ışık kontrolü sağlamak

🧠 Teknik Yöntem

  Trafik ağı, bir graf modeli olarak ele alınır.
  
  GCN mimarisi ile mekânsal + zamansal ilişkiler öğrenilir.
  
  Chebyshev / Monomial / Jacobi polinom filtreleri ile uzak arter etkisi modellenir.
  
  Tahminler gerçek zamanlı ışık kontrolüne entegre edilir.
  
  Arayüz Gradio kullanılarak geliştirilmiştir.

💾 Kullanılan Teknolojiler

  Gradio (arayüz)
